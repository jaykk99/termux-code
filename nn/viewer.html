termux-code NN — model-availability predictor

Predicts whether a registry model is listed by directModels() under a given env configuration. Pure Python stdlib, zero dependencies. Pre-check only: directModels() stays the authority, this model never enables anything.

How to use

  • node nn/build_dataset.mjs — rebuild the dataset from the registry (run after editing lib/models.mjs).
  • python3 -m nn.train — retrain from the dataset, refreshes this page's numbers.
  • python3 -m nn.score --scenario no-keys --all — rank every registry model with no keys set.
  • python3 -m nn.score --scenario only-HF_TOKEN --model hf/DavidAU/GLM-4.7-Flash-Uncensored-Heretic-NEO-CODE-Imatrix-MAX-GGUF — score one model.
